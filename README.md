# EcoEscola Emygdio: Missão Sustentabilidade

Site educacional em **HTML, CSS e JavaScript puro** desenvolvido para a professora e alunos do Ensino Fundamental. Pronto para publicação direta no **GitHub Pages** sem dependências, frameworks ou build.

---

## 🌿 Funcionalidades Principais

1. **Identificação Simples e Opcional**:
   - O aluno só precisa colocar o nome/apelido no começo do site se desejar (campo opcional). Se preferir não preencher, o sistema salva automaticamente como "Estudante Anônimo", sem travar nenhum envio.

2. **Aba 1 • Check-list de Itens Recicláveis com Pontos**:
   - Lista interativa de materiais recicláveis (Plástico, Papel, Metal, Vidro) e ações ecológicas na escola.
   - Filtros por categoria e controle de quantidade (+ / -).
   - Cálculo automático de pontos ecológicos em tempo real (+X pts por item).
   - Possibilidade de anexar fotos comprovando a reciclagem (com pré-visualização, remoção e compressão automática para caber no navegador).
   - Painel de progresso do aluno com níveis ecológicos (🌱 Semente Curiosa, 🌿 Broto Protetor, 🌳 Guardião Verde, ♻️ Agente da Reciclagem, 🌍 Mestre Sustentável).
   - Missões sustentáveis com bônus de pontuação ao atingir metas.
   - Painel de impacto coletivo da escola (água, árvores poupadas, energia, CO₂ evitado e meta de 1.000 itens).
   - Histórico local de envios com ampliação de fotos em modal, exportação em JSON e limpeza de dados.

3. **Aba 2 • Alertas & Soluções da Escola**:
   - Aba dedicada para os alunos exercerem voz ativa na escola.
   - Espaço para apontar um problema recorrente (ex.: torneira vazando, lâmpadas acesas em salas vazias, falta de lixeiras seletivas, horta precisando de cuidados) e **propor uma solução sustentável**.
   - Botões de sugestões rápidas para facilitar o preenchimento por crianças e alunos.
   - Permite anexar fotos do local ou do problema.
   - Cada alerta com solução cadastrado concede **+10 pontos ecológicos** ao aluno.
   - Mural interativo exibindo todos os alertas e soluções registrados.

4. **Armazenamento 100% Local (`localStorage`)**:
   - Não requer login, senhas ou backend.
   - Todos os registros, fotos e pontos ficam seguros no navegador do próprio aparelho do aluno ou da sala de informática.

## 🚀 Como Publicar no GitHub Pages

1. Crie um repositório no seu GitHub (ex.: `projeto-eco-escola`).
2. Envie os arquivos: `index.html`, `styles.css`, `app.js` e `README.md`.
3. No repositório, clique em **Settings** → **Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e clique em **Save**.
5. O link do site será gerado em poucos minutos pelo GitHub Pages.
